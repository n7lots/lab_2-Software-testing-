# microPaint

## Що робить застосунок

**microPaint** — це простий графічний застосунок для малювання.  
Він дозволяє користувачеві:
- Малювати від руки на полотні
- Створювати прямокутники
- Змінювати колір пера (чорний, червоний, синій)
- Очищати полотно для нового малюнка
Застосунок підтримує простий інтерфейс і працює з мишею: натискання, рух і відпускання лівої кнопки для малювання.
---

## Для кого може бути корисним

- Для **новачків у програмуванні**, які хочуть побачити роботу PySide6 і Qt
- Для **вчителів чи студентів**, що вивчають графічні застосунки на Python
- Для **користувачів**, які хочуть швидко робити ескізи чи малюнки на комп’ютері
---

## Технології, що були використані

- **Python 3.14** – мова програмування
- **PySide6 (Qt for Python)** – для створення графічного інтерфейсу
