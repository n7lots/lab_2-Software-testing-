#Порядок роботи із застосунком

# Клонування репозиторію
```bash
git clone https://github.com/your-username/drawing-app.git
cd drawing-app
```
---

# Встановлення залежностей
Перед початком роботи встановіть необхідні бібліотеки:
```bash
pip install PySide6
```
---

# Запуск проєкту
```bash
python main.py
```
Якщо є IDE Pycharm то можно скористатися зеленою кнопкою у вигляді зеленого скругленого трикутника
---

# Створення нової гілки
Перед внесенням змін створіть нову гілку:
```bash
git checkout -b назва гілки
```
або
```
git switch -c назва гілки
```
---

# Внесення змін
Після внесення змін виконайте:
```bash
git add . (або замість крапки напишіть шлях до файлу/лів які ви змінили або додали)
git commit -m "у лапках напишіть коротко що ви зробили"
```
---

# Відправка змін

```bash
git push origin назва гілки
```
---

# Створення Pull Request
1. Перейдіть у репозиторій на GitHub
2. Натисніть **New Pull Request**
3. Опишіть зміни
4. Відправте запит на злиття
---

# Правила внесення змін

* Писати зрозумілий код
* Дотримуватись стилю Python (PEP8)
* Описувати зміни у commit-повідомленнях
* Не ламати існуючу функціональність
---
